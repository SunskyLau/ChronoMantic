# 统计分析报告

## 分析概述

本报告分析了不同level(l1-l4)和category(d/u)组合下，两种工具(c/q)在time和score指标上的统计效能。

其中：
- **level**: l1, l2, l3, l4 表示不同的难度级别
- **category**: d (downward), u (upward) 表示不同的类别
- **tool**: c (ChronoMantic), q (Qetch) 表示不同的工具
- **time**: 完成任务所需的时间（秒）
- **score**: 任务完成的得分（1-7分）

统计显著性水平设置为 p < 0.05

### Time指标分析结果解释：

1. 在l2和l3的upward(u)类别中，两种工具在完成时间上存在显著差异：
   - l2u: ChronoMantic平均需要141.12秒，而Qetch只需要89.00秒，p=0.0145 < 0.05，差异显著
   - l3u: ChronoMantic平均需要99.62秒，而Qetch只需要51.25秒，p=0.0016 < 0.05，差异显著

2. 在其他level和category组合中，两种工具在完成时间上没有显著差异

3. 总体来看，在upward类别任务中，Qetch工具在完成时间上表现更好（需要更少的时间）

## 综合分析结论

### 1. 工具性能比较

**ChronoMantic (c)工具：**
- 在得分(score)方面表现优异，特别是在downward类别的所有难度级别中
- 在完成时间(time)方面，在upward类别的l2和l3级别任务中需要更多时间

**Qetch (q)工具：**
- 在upward类别的l2和l3级别任务中，完成时间显著少于ChronoMantic
- 在得分方面，除了l1u、l2u和l3u外，其他情况下得分显著低于ChronoMantic

### 2. 任务类别影响

- **Downward (d)类别：** ChronoMantic在得分上有明显优势，但完成时间与Qetch无显著差异
- **Upward (u)类别：** Qetch在l2和l3级别的完成时间上有优势，但在l4级别的得分上劣于ChronoMantic

### 3. 难度级别影响

- 随着难度增加(l1→l4)，两种工具的性能差异模式有所变化
- 在高难度级别(l3, l4)，工具选择对任务完成效果的影响更为明显

注：本分析基于t检验(假设方差不等)，显著性水平p < 0.05。样本量为每组8个观测值。

## 统计功效分析

统计功效(Statistical Power)是指在备择假设为真时，正确拒绝原假设的概率。通常，0.8或更高的功效值被认为是理想的。

2. **Score指标**：
   - 在所有downward类别中，统计功效都很高，表明当前样本量足以可靠地检测到差异

3. **样本量建议**：
   - 对于大多数功效低于0.8的组合，建议增加样本量以提高研究的可靠性
   - 特别是对于效应量小的组合(如l2_d的time指标和l2_u的score指标)，需要大量增加样本量才能达到理想功效水平
