统计分析报告

分析概述

本报告分析了不同level(l1-l4)和category(d/u)组合下，两种工具(c/q)在time和score指标上的统计效能。

其中：

  • level: l1, l2, l3, l4 表示不同的难度级别
  • category: d (downward), u (upward) 表示不同的类别
  • tool: c (ChronoMantic), q (Qetch) 表示不同的工具
  • time: 完成任务所需的时间（秒）
  • score: 任务完成的得分（1-7分）

统计显著性水平设置为 p < 0.05

综合分析结论

1. 工具性能比较

ChronoMantic (c)工具：

  • 在得分(score)方面表现优异，特别是在downward类别的所有难度级别中
  • 在完成时间(time)方面，在upward类别的l2和l3级别任务中需要更多时间

Qetch (q)工具：

  • 在upward类别的l2和l3级别任务中，完成时间显著少于ChronoMantic
  • 在得分方面，除了l1u、l2u和l3u外，其他情况下得分显著低于ChronoMantic

2. 任务类别影响

  • Downward (d)类别： ChronoMantic在得分上有明显优势，但完成时间与Qetch无显著差异
  • Upward (u)类别： Qetch在l2和l3级别的完成时间上有优势，但在l4级别的得分上劣于ChronoMantic

3. 难度级别影响

  • 随着难度增加(l1→l4)，两种工具的性能差异模式有所变化
  • 在高难度级别(l3, l4)，工具选择对任务完成效果的影响更为明显

注：本分析基于t检验(假设方差不等)，显著性水平p < 0.05。样本量为每组8个观测值。
